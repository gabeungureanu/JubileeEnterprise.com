Sprint 1.1: Value Converters Implementation

Objective: Implement all 22 value converters currently throwing NotImplementedException

Dependencies: None - can start immediately

Step-by-Step Tasks:

  1. 1
    Implement Visibility Converters
    BoolToVisibilityConverter - Convert bool to Visibility.Visible/Collapsed
    InverseBoolToVisibilityConverter - Inverse of above
    NullToVisibilityConverter - Show/hide based on null check
    StringToVisibilityConverter - Show/hide based on empty string
    CountToVisibilityConverter - Show/hide based on collection count
  2. 2
    Implement Text/Style Converters
    ReadToWeightConverter - Bold for unread, Normal for read
    ListToStringConverter - Join list items with separator
  3. 3
    Implement Calendar Date Converters
    IsTodayConverter - Check if date is today
    IsTodayToBackgroundConverter - Gold background for today
    IsTodayToForegroundConverter - Text color for today
    IsTodayToFontWeightConverter - Bold for today
  4. 4
    Implement Calendar Event Converters
    EventHeightConverter - Calculate event height (60px per hour)
    EventTopPositionConverter - Calculate event top position
    EventsForDayColumnConverter - Filter events by date
    EventsByDateConverter - Group events by date
    EventColorConverter - Get event color from category
  5. 5
    Unit Test All Converters
    Create test cases for each converter with edge cases
Deliverables:
  • 22 fully implemented value converters in Helpers/Converters.cs
  • Unit tests for all converters
  • No more NotImplementedException errors
Technical Notes:
  • File: JubileeOutlook/Helpers/Converters.cs
  • All converters implement IValueConverter or IMultiValueConverter
  • Use existing theme colors from DarkTheme.xaml

    CreateEventAsync() - POST /api/outlook/events
    UpdateEventAsync() - PUT /api/outlook/events/{id}
    DeleteEventAsync() - DELETE /api/outlook/events/{id}
  4. 4
    Implement ApiMailService
    GetFoldersAsync() - GET /api/outlook/folders
    GetMessagesAsync() - GET /api/outlook/messages
    SendMessageAsync() - POST /api/outlook/messages
    DeleteMessageAsync() - DELETE /api/outlook/messages/{id}
    MoveMessageAsync() - PUT /api/outlook/messages/{id}/move
  5. 5
    Update ServiceConfiguration
    Toggle between Mock and API services
    Read CONTINUUM_API_URL from environment
    Pass authenticated user ID to services
  6. 6
    Error Handling & Retry Logic
    Implement Polly for retry policies
    Handle network failures gracefully
    Show user-friendly error messages

  • Fully working ApiCalendarService
  • Fully working ApiMailService
  • Environment-based configuration
  • Robust error handling
Technical Notes:
  • API Base URL: http://localhost:3101 (dev) or https://api.inspirecontinuum.com (prod)
  • All requests require Authorization: Bearer {token} header
  • Consider adding NuGet: Microsoft.Extensions.Http.Polly for retry policies
