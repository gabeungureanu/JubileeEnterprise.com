### Tunnel Commands Reference

```powershell
# Start the tunnel
cloudflared tunnel run

# Route DNS for a new domain (after adding zone to Cloudflare)
cloudflared tunnel route dns c4c875e2-55a9-4ad7-a0e9-36c391229c0b <domain>
cloudflared tunnel route dns c4c875e2-55a9-4ad7-a0e9-36c391229c0b www.<domain>

# List tunnel routes
cloudflared tunnel route dns list

# Validate config
cloudflared tunnel ingress validate
```

### Adding a New Domain to the Tunnel

1. **Add domain zone to Cloudflare Dashboard**
   - Go to Cloudflare Dashboard → Add Site
   - Enter domain name
   - Select plan
   - Update nameservers at registrar

2. **Add ingress entry to config.yml**
   ```yaml
   - hostname: newdomain.com
     service: http://localhost:PORT
   - hostname: www.newdomain.com
     service: http://localhost:PORT
   ```

3. **Route DNS to tunnel**
   ```powershell
   cloudflared tunnel route dns c4c875e2-55a9-4ad7-a0e9-36c391229c0b newdomain.com
   cloudflared tunnel route dns c4c875e2-55a9-4ad7-a0e9-36c391229c0b www.newdomain.com
   ```

4. **Restart tunnel**
   ```powershell
   cloudflared tunnel run
   ```
