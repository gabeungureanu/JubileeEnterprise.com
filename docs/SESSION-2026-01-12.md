## 1. wwBibleweb.com Pentecostal Home Page - Full-Width Responsive Layout

### Problem

The pentecostal home page at `https://www.wwbibleweb.com/pentecostal/home/index.html` was using a fixed `max-width: 1200px` layout that didn't scale well across different screen resolutions. The user requested a CNN.com-style full-width responsive layout that stretches to the full viewport width while maintaining aspect ratios for all elements including font sizes.

### Solution Implemented

Implemented CSS custom properties with `clamp()` functions for fluid typography and spacing that scales proportionally with viewport width.

### CSS Custom Properties Added

```css
:root {
  /* Fluid spacing scale using clamp() */
  --space-xs: clamp(0.25rem, 0.5vw, 0.5rem);
  --space-sm: clamp(0.5rem, 1vw, 1rem);
  --space-md: clamp(1rem, 2vw, 1.5rem);
  --space-lg: clamp(1.5rem, 3vw, 2.5rem);
  --space-xl: clamp(2rem, 4vw, 4rem);

  /* Fluid typography scale */
  --font-xs: clamp(0.625rem, 0.5rem + 0.25vw, 0.75rem);
  --font-sm: clamp(0.75rem, 0.65rem + 0.35vw, 0.875rem);
  --font-base: clamp(0.875rem, 0.75rem + 0.5vw, 1rem);
  --font-md: clamp(1rem, 0.85rem + 0.6vw, 1.125rem);
  --font-lg: clamp(1.125rem, 0.9rem + 0.8vw, 1.375rem);
  --font-xl: clamp(1.25rem, 1rem + 1vw, 1.75rem);
  --font-2xl: clamp(1.5rem, 1.1rem + 1.5vw, 2.25rem);
  --font-3xl: clamp(1.75rem, 1.2rem + 2vw, 2.75rem);
  --font-4xl: clamp(2rem, 1.3rem + 2.5vw, 3.25rem);

  /* Full-width container with maximum cap */
  --content-max: min(100%, 2400px);
  --container-padding: clamp(1rem, 3vw, 4rem);
}
```

### Changes Made

| Element | Before | After |
|---------|--------|-------|
| Container max-width | `1200px` | `var(--content-max)` (min(100%, 2400px)) |
| Container padding | Fixed values | `var(--container-padding)` |
| Grid columns | Fixed `350px` | `clamp(280px, 22vw, 350px)` |
| Typography | Fixed pixel values | Fluid `clamp()` functions |
| Spacing | Fixed pixel values | CSS custom properties |

### Technical Details

- **Fluid Typography**: Font sizes scale smoothly between minimum and maximum values based on viewport width using the `clamp(min, preferred, max)` function
- **Viewport Units**: The preferred value uses viewport width (vw) units to create smooth scaling
- **Maximum Cap**: Content is capped at 2400px to prevent excessive stretching on ultra-wide monitors
- **Aspect Ratio Preservation**: All elements scale proportionally, maintaining visual consistency across screen sizes

## 2. wwBibleweb.com 502 Bad Gateway Fix

### Problem

The wwBibleweb.com website was returning a 502 Bad Gateway error when accessed through Cloudflare tunnel.

### Root Cause

1. The wwBibleweb Express server was not running
2. Initial fix attempt started the server on wrong port (3000 instead of 3847)
3. Cloudflare tunnel configuration expects wwBibleweb.com on port 3847

### Investigation Steps

1. Checked Cloudflare tunnel config at `C:\Users\elian\.cloudflared\config.yml`
2. Verified port mapping: `wwbibleweb.com` → `localhost:3847`
3. Started server with correct PORT environment variable

### Fix Applied

```bash
# Started wwBibleweb server on correct port
cd c:\data\JubileeEnterprise.com\websites\codex\wwBibleweb.com
PORT=3847 node server.js
```

Verified with curl:
```bash
curl -I https://www.wwbibleweb.com/pentecostal/home/index.html
# HTTP/2 200
```

## 4. JubileeInspire.ios Mobile App - TypeScript Fix

### Problem

The JubileeInspire.ios Expo/React Native mobile app would not start due to TypeScript not being installed, despite being listed in `devDependencies`.

### Error Messages

```
Error: TypeScript ~5.9.2 is required. Run `npx expo install typescript` to install.
```

### Root Cause

NPM was running in production mode by default, which skips installation of `devDependencies`. The `npm install` command was only installing 674 packages (production dependencies) and ignoring TypeScript.

### Fix Applied

1. **Fixed package.json** - Changed TypeScript from local tarball reference to proper version:

```json
{
  "devDependencies": {
    "@types/react": "~19.1.0",
    "typescript": "^5.9.2"
  }
}
```

2. **Installed with dev dependencies**:

```bash
npm install --include=dev
```

This added TypeScript as the 675th package.

3. **Started Expo web server**:

```bash
npx expo start --web --port 19006
```

### Result

- Metro bundler successfully compiled 1080 modules in 1624ms
- App accessible at http://localhost:19006
- Can be viewed in mobile mode using browser DevTools device emulation

## Key Learnings

1. **CSS Custom Properties with clamp()**: Provides truly responsive design that scales smoothly across all viewport sizes while maintaining aspect ratios

2. **NPM Production Mode**: By default, `npm install` may skip devDependencies. Use `npm install --include=dev` to ensure all dependencies are installed

3. **Port Configuration**: Always verify service ports match infrastructure configuration (Cloudflare tunnel, reverse proxy, etc.)

4. **PM2 Ecosystem**: All production services should be added to ecosystem.config.cjs for automatic process management
