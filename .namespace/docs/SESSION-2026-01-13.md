## 1. Jubilee Tasks Extension - Production API Configuration

### Problem

The Jubilee Tasks extension was configured to use `http://localhost:3100` as the default API URL, causing "Failed to load tasks" errors when the local InspireCodex API was not running.

### Solution Implemented

Changed the default API URL in `package.json` from `http://localhost:3100` to `https://www.inspirecodex.com` (production API).

### Files Modified

- `extensions/jubilee-tasks/package.json` - Updated default `apiBaseUrl` setting

### Configuration Change

```json
"jubileeTasks.apiBaseUrl": {
  "type": "string",
  "default": "https://www.inspirecodex.com",
  "description": "Base URL for the InspireCodex API"
}
```

## 2. Jubilee Tasks Extension - Submit Button Fix

### Problem

The Submit button for entering developer initials was not responding to clicks in VS Code webviews.

### Root Cause

Inline `onclick` attributes (e.g., `onclick="submitInitials()"`) are blocked by VS Code webview Content Security Policy (CSP).

### Solution Implemented

Removed inline `onclick` attribute and attached click handler programmatically using `addEventListener`.

### Files Modified

- `extensions/jubilee-tasks/src/webview-provider.ts`

### Code Change

**Before:**
```html
<button type="button" id="initials-submit" class="initials-submit" onclick="submitInitials()">Submit</button>
```

**After:**
```html
<button type="button" id="initials-submit" class="initials-submit">Submit</button>
```

```javascript
submitBtn.addEventListener('click', function(e) {
  e.preventDefault();
  e.stopPropagation();
  submitInitials();
});
```

## 4. Mobile App - Action Bar Tooltip Fix

### Problem

Tooltips on the ChatGPT-style action bar icons were being cut off/truncated when hovering over them.

### Solution Implemented

Updated tooltip styles to prevent text cutoff:

1. Added `zIndex: 100` to `actionButtonWrapper` for proper stacking
2. Added `minWidth: 70` to tooltip style to ensure minimum width
3. Removed `alignItems: 'center'` from tooltip (was constraining width)
4. Changed `whiteSpace: 'nowrap'` to `textAlign: 'center'` for better compatibility

### Files Modified

- `mobile/JubileeInspire.ios/src/components/MessageBubble.tsx`

### Style Changes

```typescript
tooltip: {
  position: 'absolute',
  top: '100%',
  left: '50%',
  transform: [{ translateX: '-50%' }],
  paddingHorizontal: 8,
  paddingVertical: 4,
  borderRadius: 4,
  marginTop: 4,
  zIndex: 1000,
  minWidth: 70,  // Added
},
tooltipText: {
  fontSize: 11,
  fontWeight: '500',
  textAlign: 'center',  // Changed from whiteSpace: 'nowrap'
},
```

## 5. Mobile App - More Options Click-Outside Handler

### Problem

The "More Options" popup menu (ellipsis icon) did not close when clicking outside of it.

### Solution Implemented

Added an invisible full-screen overlay that captures clicks outside the menu and closes it.

### Files Modified

- `mobile/JubileeInspire.ios/src/components/MessageBubble.tsx`

### Implementation

```typescript
{showMoreMenu && (
  <>
    {/* Invisible overlay to capture clicks outside the menu */}
    <Pressable
      style={styles.menuOverlay}
      onPress={() => setShowMoreMenu(false)}
    />
    <View style={[styles.moreMenu, ...]}>
      {/* Menu items */}
    </View>
  </>
)}
```

```typescript
menuOverlay: {
  position: 'fixed',
  top: 0,
  left: 0,
  right: 0,
  bottom: 0,
  zIndex: 1000,
},
```
