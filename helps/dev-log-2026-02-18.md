## Technical Notes

- **API Layer**: All services use the dual Axios client pattern. `codexClient` → InspireCodex.com (auth, contacts). `continuumClient` → InspireContinuum.com (mail, calendar, sync). No direct database connections.

- **Auth Screen Pattern**: The web uses a single `SignIn.tsx` component with 5 panel states (`sync`, `sync-password`, `signin`, `signup`, `forgot`). Mobile uses 5 separate React Navigation screens — the standard mobile pattern — sharing a common `AuthCard` layout wrapper.

- **Gold Color Strategy**: Web uses `#FFD700` (pure gold) for auth accent. Mobile had `#ffbd59` (amber) for other UI. Auth-specific gold constants were added to `colors.ts` to match web exactly without disrupting existing screens.

- **Validation Logic**: Matches web exactly — `EMAIL_REGEX = /^[^@\s]+@[^@\s]+\.[^@\s]+$/`, name >= 2 chars, password >= 6 chars, passwords must match. Real-time error clearing on valid input.

- **Provider Detection**: `emailSyncService.detectProvider()` returns `ProviderInfo` with IMAP/SMTP settings, display name, and help text. Used by SyncPasswordScreen to show appropriate password label and instructions.

- **Expo SDK 54**: Using Expo SDK 54 for Expo Go compatibility. React Native 0.81.5, TypeScript 5.9.2. All TypeScript checks pass with 0 errors.
