## Mobile App: JubileeOutlookMobile (Phase 2)

### 1. Auth Flow Fix (Critical)

**Problem:** After successful IMAP sync, the user got stuck on SignIn instead of auto-navigating to the Mail inbox. AuthContext bootstrap only ran once on mount.

**Fix:**
- Added `refreshAuthState()` method to `AuthContext.tsx` — callable on demand, mirrors bootstrap logic
- `SyncPasswordScreen.tsx` now calls `refreshAuthState()` instead of `navigation.reset()` after sync
- When `isAuthenticated` flips to `true`, `RootNavigator` auto-switches from AuthStack to MainTabs

**Files:** `src/context/AuthContext.tsx`, `src/screens/auth/SyncPasswordScreen.tsx`

### 2. Calendar Month Off-By-One Fix

**Problem:** `CalendarScreen.tsx` called `getEventsForMonth(year, month + 1)` but `month` was already 0-indexed from `new Date().getMonth()`, causing events to load for the wrong month.

**Fix:** Removed `+ 1` from the month parameter.

**File:** `src/screens/calendar/CalendarScreen.tsx`

### 5. Mail Screen — Complete Rebuild

The `MailScreen.tsx` was substantially rebuilt with the following features:

#### 5a. Sidebar Drawer
- New `SidebarDrawer` component (`src/components/modules/mail/SidebarDrawer.tsx`)
- Two-column layout: icon rail (left) + folder list (right)
- Animated slide-in/out with Modal overlay
- Shows user avatar, email, account switcher, and all mail folders with unread counts

#### 5b. Date-Based Section Grouping
- Replaced `FlatList` with `SectionList` for date-grouped inbox rendering
- Sections: **This Week**, **Last Week**, **This Month**, **Last Month**, **Older**
- Helper functions: `getStartOfWeek()`, `getDateSection()`, `buildSections()`
- Section headers with uppercase labels, dividers between sections

#### 5c. Focus/Other Toggle + Filter Menu
- Focused/Other toggle (Focused = Inbox, Other = Junk/Spam)
- Filter dropdown with options: All, Unread, Flagged, Pinned, Has Files, Mention Me

#### 5d. IMAP Sync Fix
- `handleSync` now calls `mailService.syncAccount()` for each account before fetching messages (mirrors web frontend's `syncAll` pattern)
- Preserves local read status during sync — captures `readIds` before fetch, merges back after
- Counts new emails by comparing message IDs (not array lengths which fail with pagination)

#### 5e. Auto-Refresh on Focus
- Added `navigation.addListener('focus')` to re-fetch messages when screen regains focus
- Fixes inbox not showing self-sent emails after composing

#### 5f. Read State Management
- `handleMessagePress` locally sets `isRead: true` before navigating to detail
- Blue unread dot disappears immediately without waiting for API response
- Read state preserved across sync and focus refresh

#### 5g. Long-Press Email Selection Mode
- Long-press any email to enter selection mode
- Multi-select with circular checkboxes replacing avatars
- Selection mode header: checkmark icon + count + delete/archive/more-vert buttons
- Three-dot menu: Move to Folder, Move to Other, Mark as Read, Flag, Pin (disabled), Select All/Unselect All
- Folder picker modal for "Move to Folder" action
- Bulk actions: `handleBulkDelete`, `handleBulkArchive`, `handleBulkMarkRead`, `handleBulkFlag`, `handleBulkMoveToOther`, `handleBulkMoveToFolder`
- Toggle Select All / Unselect All behavior

**Files:** `src/screens/mail/MailScreen.tsx`, `src/components/modules/mail/SidebarDrawer.tsx` (new)

## Technical Notes

- **Pagination-safe sync counting**: New email count uses ID comparison (`prevIds` → `merged.filter(m => !prevIds.has(m.id)).length`) instead of array length comparison, which fails when results are capped at 50.
- **Read state preservation**: Both sync and focus refresh merge local read IDs back into fresh messages to prevent IMAP overwriting `is_read` flags.
- **Selection mode pattern**: `selectedIds: Set<string>` with derived `isSelectionMode = selectedIds.size > 0`. Long-press enters, checkmark icon exits.
- **SectionList**: React Native's `SectionList` used for date-grouped rendering with sticky headers disabled.
- **Browser notifications**: Calendar reminders now fire OS-native notifications via the Notification API, with `requireInteraction: true` and window focus on click.
