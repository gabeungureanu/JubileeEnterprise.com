### 3. ThemedAlert — Outlined Icon Variants + Icon Override System

Updated ThemedAlert variant icons to outlined style AND added optional `icon`/`iconColor` props for per-call-site customization.

**Variant icon changes:**

| Variant | Before | After |
|---------|--------|-------|
| info | `info` | `info-outline` |
| success | `check-circle` | `check-circle-outline` |
| error | `error` | `error-outline` |
| warning | `warning` | `warning` (unchanged) |
| confirm | `help` | `delete-forever` |

**New props added to `ThemedAlertProps`:**

```typescript
/** Override the variant's default icon (MaterialIcons name). */
icon?: string;
/** Override the variant's default accent color. */
iconColor?: string;
```

The component uses the override if provided, otherwise falls back to the variant's default icon/color.

**File:** `mobile/JubileeOutlookMobile/src/components/common/ThemedAlert.tsx`

---

### 4. useAlert Hook — Icon Override Support in confirm()

Extended `AlertState` interface and `confirm()` options to pass `icon` and `iconColor` through to ThemedAlert.

```typescript
// New confirm options:
options?: {
  confirmText?: string;
  cancelText?: string;
  variant?: AlertVariant;
  destructive?: boolean;
  icon?: string;       // NEW
  iconColor?: string;  // NEW
}
```

**File:** `mobile/JubileeOutlookMobile/src/hooks/useAlert.tsx`
