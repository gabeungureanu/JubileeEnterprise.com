## 3. Login CORS Fix (from previous session)

### Problem
Login was failing with "An error occurred. Please try again." due to CORS issues when calling `https://inspirecodex.com/api/auth/login` directly from localhost.

### Solution
Added auth proxy endpoint to the local server that forwards authentication requests to InspireCodex.com, avoiding CORS restrictions.

**Server Changes (`server.js`):**
```javascript
// Auth API proxy (local development - avoids CORS issues)
if (pathname.startsWith('/api/auth/')) {
    handleAuthProxy(req, res, pathname);
    return;
}
```

**Client Changes (`login.html`, `chat.html`):**
```javascript
var isLocalDev = window.location.hostname === 'localhost' || window.location.hostname === '127.0.0.1';
var API = isLocalDev ? '' : 'https://inspirecodex.com';
```
