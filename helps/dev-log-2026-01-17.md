## 1. JubileeBrowser WPF - To-Do List Enhancements

### Overview
This update improves the To-Do List panel with a loading indicator and fixes for task editing functionality.

### Completed Features

#### To-Do List Loading Indicator
- **Spinning Loader**: Gold-colored (#E6AC00) ring animation while tasks are fetched
- **Transparent Background**: Loader blends seamlessly with panel background
- **Auto-Hide**: Indicator disappears when tasks are loaded
- **Initial State**: Starts as `Collapsed` and only shows during API fetch

**Technical Implementation:**
```xml

        Background="Transparent"
        Visibility="Collapsed"
        VerticalAlignment="Center"
        HorizontalAlignment="Center">
    <StackPanel>
        <Border Width="32" Height="32" CornerRadius="16"
                BorderBrush="#E6AC00" BorderThickness="3">
            <!-- Spinning animation via Storyboard -->
        </Border>
        <TextBlock Text="Loading tasks..." Foreground="#888"/>
    </StackPanel>
</Border>
```

**Files Modified:**
- `MainWindow.xaml` - Added `TodoLoadingIndicator` Border element (lines 2802-2837)
- `MainWindow.xaml.cs` - Show/hide indicator in `LoadTodosAsync()` method

#### To-Do List Edit Glitch Fix
- **Issue**: Tasks would disappear after editing, only reappearing after reopening the panel
- **Root Cause**: List wasn't re-sorted after edit operations
- **Solution**: Added LINQ `OrderBy` re-sorting after successful API updates

**Code Changes in `SaveTodoEdit_Click()`:**
```csharp
// Re-sort the list to maintain correct order (incomplete first, then by creation date)
_todoItems = _todoItems
    .OrderBy(t => t.IsCompleted)
    .ThenBy(t => t.CreatedAt)
    .ToList();
TodoItemsControl.ItemsSource = _todoItems;
```

## 2. JubileeBrowser WPF - Sidebar Active State Indicators

### Overview
Added visual feedback for active sidebar panels with gold indicator dots on Bookmarks and History icons.

### Completed Features

#### Sidebar Bookmarks Active Indicator
- **Gold Dot**: 8x8 pixel ellipse with #E6AC00 fill color
- **Glow Effect**: DropShadow effect for enhanced visibility
- **Position**: Top-right corner of the icon
- **Toggle**: Visible when Bookmarks panel is open, collapsed otherwise

#### Sidebar History Active Indicator
- Same styling as Bookmarks indicator
- Independent visibility control

**XAML Implementation:**
```xml
<!-- Active indicator dot -->
<Ellipse x:Name="SidebarBookmarksActiveIndicator"
         Width="8" Height="8"
         Fill="#E6AC00"
         HorizontalAlignment="Right"
         VerticalAlignment="Top"
         Margin="0,-2,-2,0"
         Visibility="Collapsed">
    <Ellipse.Effect>
        <DropShadowEffect Color="#E6AC00" BlurRadius="6"
                          ShadowDepth="0" Opacity="0.8"/>
    </Ellipse.Effect>
</Ellipse>
```

#### Helper Methods
Created reusable methods for managing active states:

```csharp
private void SetSidebarBookmarksActive(bool isActive)
{
    SidebarBookmarksButton.Tag = isActive ? "Active" : null;
    SidebarBookmarksActiveIndicator.Visibility = isActive
        ? Visibility.Visible : Visibility.Collapsed;
}

private void SetSidebarHistoryActive(bool isActive)
{
    SidebarHistoryButton.Tag = isActive ? "Active" : null;
    SidebarHistoryActiveIndicator.Visibility = isActive
        ? Visibility.Visible : Visibility.Collapsed;
}
```

#### Panel Switching Logic
- **Bookmarks Click**: Activates bookmarks indicator, deactivates history
- **History Click**: Activates history indicator, deactivates bookmarks
- **Todo/Chat Click**: Deactivates both Bookmarks and History indicators
- **Close Panel**: Deactivates respective indicator

**Files Modified:**
- `MainWindow.xaml` - Added indicator ellipses to SidebarBookmarksButton and SidebarHistoryButton
- `MainWindow.xaml.cs` - Added helper methods and updated click handlers

## 3. JubileeBrowser WPF - Bug Fixes

### Hamburger Menu Icon in Yellow Mode
- **Issue**: When opening a new tab in yellow mode with the sidebar open, the hamburger icon turned black instead of staying white
- **Root Cause**: Line 3162 in `UpdateModeVisuals()` always set the icon to black, regardless of sidebar state
- **Solution**: Added check for `_isSidebarOpen` before setting color

**Before:**
```csharp
SidebarToggleIcon.Foreground = blackBrush;
```

**After:**
```csharp
SidebarToggleIcon.Foreground = _isSidebarOpen
    ? System.Windows.Media.Brushes.White : blackBrush;
```
