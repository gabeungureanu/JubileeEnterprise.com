## 2. Reply/Reply All/Forward Architecture

### Overview
Implemented a complete event-based architecture for Reply, Reply All, and Forward email operations. The buttons are currently hidden pending body display improvements.

### Architecture Changes

#### MainViewModel.cs - Events Added
```csharp
public event EventHandler? ReplyRequested;
public event EventHandler? ReplyAllRequested;
public event EventHandler? ForwardRequested;

[RelayCommand]
private void Reply()
{
    if (DisplayedMessage == null) return;
    ReplyRequested?.Invoke(this, EventArgs.Empty);
}

[RelayCommand]
private void ReplyAll()
{
    if (DisplayedMessage == null) return;
    ReplyAllRequested?.Invoke(this, EventArgs.Empty);
}

[RelayCommand]
private void Forward()
{
    if (DisplayedMessage == null) return;
    ForwardRequested?.Invoke(this, EventArgs.Empty);
}
```

#### MainWindow.xaml.cs - Event Subscriptions
```csharp
// In constructor
_mainViewModel.ReplyRequested += (s, e) => Dispatcher.Invoke(ShowComposePanelForReply);
_mainViewModel.ReplyAllRequested += (s, e) => Dispatcher.Invoke(ShowComposePanelForReplyAll);
_mainViewModel.ForwardRequested += (s, e) => Dispatcher.Invoke(ShowComposePanelForForward);
```

#### MainWindow.xaml.cs - Compose Panel Methods
Added three new methods:
- `ShowComposePanelForReply()` - Opens compose panel with "Re:" prefix and quoted body
- `ShowComposePanelForReplyAll()` - Opens compose panel with all recipients

## 3. ComposeMailView Enhancements

### SetBodyContent Method
Added method to programmatically set email body content:
```csharp
public void SetBodyContent(string bodyText)
{
    if (MessageBodyEditor == null || string.IsNullOrEmpty(bodyText)) return;
    MessageBodyEditor.Document.Blocks.Clear();
    var displayText = bodyText;
    if (bodyText.Contains("<") && bodyText.Contains(">"))
    {
        displayText = ConvertHtmlToPlainText(bodyText);
    }
    var lines = displayText.Split(new[] { "\r\n", "\n", "\r" }, StringSplitOptions.None);
    foreach (var line in lines)
    {
        var paragraph = new Paragraph(new Run(line));
        MessageBodyEditor.Document.Blocks.Add(paragraph);
    }
    MessageBodyEditor.CaretPosition = MessageBodyEditor.Document.ContentStart;
    MessageBodyEditor.Focus();
}
```

### HTML-to-Plain Text Converter
Added comprehensive HTML to plain text conversion:
```csharp
private string ConvertHtmlToPlainText(string html)
{
    // Remove inline images
    text = Regex.Replace(text, @"<img[^>]*>", "", RegexOptions.IgnoreCase);

    // Replace common HTML entities
    text = text.Replace("&nbsp;", " ")
               .Replace("&amp;", "&")
               .Replace("&lt;", "<")
               .Replace("&gt;", ">")
               .Replace("&quot;", "\"")
               .Replace("&#39;", "'");

    // Convert br, p, div tags to newlines
    text = Regex.Replace(text, @"<br\s*/?>", "\n", RegexOptions.IgnoreCase);
    text = Regex.Replace(text, @"</p>", "\n\n", RegexOptions.IgnoreCase);
    text = Regex.Replace(text, @"</div>", "\n", RegexOptions.IgnoreCase);

    // Remove remaining HTML tags
    text = Regex.Replace(text, @"<[^>]+>", "");

    // Clean up whitespace
    text = Regex.Replace(text, @"\n{3,}", "\n\n");

    return text.Trim();
}
```
