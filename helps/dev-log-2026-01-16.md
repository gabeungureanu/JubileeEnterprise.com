### DialogResult Fix
The animation callbacks in custom dialogs caused a `DialogResult can be set only after Window is created and shown as dialog` error. Fixed by wrapping DialogResult assignment in try-catch:

```csharp
try { DialogResult = true; }
catch (InvalidOperationException) { }
Close();
```

### 6. Start in Jubilee Bibles Mode Fix

Fixed the "Start in Jubilee Bibles mode" toggle that wasn't working.

#### Problem
The session state's mode was overriding the DefaultMode setting on startup.

#### Solution (MainWindow.xaml.cs lines 433-443)
Changed startup logic to always respect the DefaultMode setting instead of using the session's saved mode:
```csharp
if (_startupMode.HasValue)
{
    _currentMode = _startupMode.Value;
}
else
{
    // Always respect the DefaultMode setting
    _currentMode = settings?.DefaultMode ?? BrowserMode.Internet;
}
```
