# Development Log - January 16, 2026

## Summary

Today's development session focused on improving the Jubilee Browser user interface by replacing all system MessageBox dialogs with custom Jubilee-themed modals, implementing in-app document viewing for legal documents, and adding profile picture upload functionality.

Replaced all system `MessageBox` calls with custom Jubilee-themed dialogs to maintain consistent branding throughout the application.

  - Warning icon with amber color

#### Legal Documents
- **Files**: `Resources/termsofuse.yaml`, `Resources/privacypolicy.yaml`
- **Content**: Full legal documents with proper formatting
- **Structure**: `title`, `lastUpdated`, `sections` (heading + content)

### DialogResult Fix
The animation callbacks in custom dialogs caused a `DialogResult can be set only after Window is created and shown as dialog` error. Fixed by wrapping DialogResult assignment in try-catch:

```csharp
try { DialogResult = true; }
catch (InvalidOperationException) { }
Close();
```

### Profile Picture Storage
- Directory: `%LocalAppData%\JubileeBrowser\ProfilePictures`
- Filename format: `{userId}_avatar{extension}`
- Supported formats: JPG, JPEG, PNG, GIF, BMP
