## 1. New InputDialog Component

### Overview
Created a reusable modal dialog for text input operations such as creating new folders, renaming items, etc.

- Custom borderless window style with rounded corners
- Draggable title bar
- Gold (#FFD700) accent color for title and OK button
- Dark theme consistent styling (#1A1A1A background)

## 2. Contact Photo Management

### Overview
Added comprehensive contact photo upload and delete functionality to the ImageService.

### ImageService.cs Enhancements

#### New Methods

**`UploadContactPhotoAsync(string localFilePath)`**
- Uploads a contact photo to the InspireCodex API
- Returns the URL of the uploaded photo
- Supports various image formats (determined by file extension)
- Uses multipart form data for file upload
- Proper error handling and logging

**`DeleteContactPhotoAsync(string photoUrl)`**
- Deletes a contact photo from the server
- Extracts filename from URL (supports both absolute and relative URLs)
- Returns boolean indicating success/failure

#### New Response Model
```csharp
internal class ContactPhotoUploadResponse
{
    public bool Success { get; set; }
    public string? PhotoUrl { get; set; }
    public string? Filename { get; set; }
    public long Size { get; set; }
    public string? Error { get; set; }
}
```

## 4. MailFolder Model Enhancement

### Overview
Changed `SubFolders` property from `List<MailFolder>` to `ObservableCollection<MailFolder>` for proper WPF data binding and UI updates.

### Change Details
```csharp
// Before
public List<MailFolder> SubFolders { get; set; } = new();

// After
public ObservableCollection<MailFolder> SubFolders { get; set; } = new();
```

### Rationale
- `ObservableCollection<T>` implements `INotifyCollectionChanged`
- Enables automatic UI updates when folders are added/removed
- Required for proper TreeView binding in the folder navigation
