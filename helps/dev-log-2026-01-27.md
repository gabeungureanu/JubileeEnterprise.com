# Development Log - January 27, 2026

## Summary

Added local development chat API support to JubileeInspire.com, enabling the chat functionality to work without requiring the full InspireCodex.com API infrastructure. This resolves the "Connection error" issue when using the chat in local development environments.

---

## 1. JubileeInspire.com Local Chat API

### Problem
When running JubileeInspire.com locally, the chat functionality displayed "Connection error. Please check your internet and try again." This occurred because:
- The chat.html was configured to use `https://inspirecodex.com` for the Chat API
- InspireCodex.com API requires PostgreSQL database connection to start
- Local development environments may not have the full database infrastructure running

### Solution
Added a local `/Home/ChatWithJubilee` endpoint directly to the JubileeInspire.com server, mirroring the InspireCodex.com API functionality.

## 2. Technical Changes

### Modified Files

#### `websites/codex/JubileeInspire.com/server.js`

**Changes:**
1. Added environment variable loading from root `.env` file
2. Added `parseJsonBody()` function for handling POST request bodies
3. Added `handleChatAPI()` function implementing the `/Home/ChatWithJubilee` endpoint
4. Added route handler for POST `/Home/ChatWithJubilee`
5. Updated port documentation comment (3001 for development)

**New Endpoint:**
```
POST /Home/ChatWithJubilee
```

**Request Body:**
```json
{
  "message": "User's message",
  "conversationHistory": [],
  "personaName": "Jubilee Inspire",
  "conversationId": null,
  "inspireModel": "gospelpulse",
  "systemPrompt": "",
  "developerPrompt": ""
}
```

**Response:**
```json
{
  "success": true,
  "response": "AI response text",
  "model": "gpt-4o-mini",
  "personaName": "Jubilee Inspire",
  "conversation": {
    "id": "inspire-timestamp-random",
    "title": "Message preview...",
    "isNew": true,
    "personaName": "Jubilee Inspire",
    "lastMessage": "Response preview...",
    "timestamp": "ISO timestamp"
  },
  "usage": { /* OpenAI usage stats */ },
  "processingTimeMs": 1234
}
```

#### `websites/codex/JubileeInspire.com/chat.html`

**Changes:**
1. Added automatic localhost detection
2. Added `isLocalDev` variable to detect development environment
3. Modified `CHAT_API` to use empty string (same-origin) for localhost
4. Added console log for local development mode

**Before:**
```javascript
var AUTH_API = 'https://inspirecodex.com';
var CHAT_API = 'https://inspirecodex.com';
```

**After:**
```javascript
var isLocalDev = window.location.hostname === 'localhost' || window.location.hostname === '127.0.0.1';
var AUTH_API = 'https://inspirecodex.com';
var CHAT_API = isLocalDev ? '' : 'https://inspirecodex.com';

if (isLocalDev) {
    console.log('Running in local development mode - using local chat API');
}
```

## 3. Environment Requirements

For the local chat API to work, the following environment variable must be configured in the root `.env` file:

```
OPENAI_API_KEY=sk-your-actual-openai-key
```

The server will display an error message if the API key is not configured or still set to the placeholder value.

## 4. Architecture Notes

### Local Development Flow
```
User Browser (localhost:3001/chat)
       │
       ▼
JubileeInspire.com Server (port 3001)
       │
       ├── GET /chat → serves chat.html
       │
       └── POST /Home/ChatWithJubilee
              │
              ▼
         OpenAI API (gpt-4o-mini)
              │
              ▼
         JSON Response
```

### Production Flow (Unchanged)
```
User Browser (jubileeinspire.com/chat)
       │
       ▼
JubileeInspire.com (static files)
       │
       └── POST to inspirecodex.com/Home/ChatWithJubilee
              │
              ▼
         InspireCodex.com API
              │
              ├── RAG Context (Qdrant)
              │
              └── OpenAI API
                     │
                     ▼
               JSON Response
```

## 8. Known Limitations

1. **No RAG Support**: The local development endpoint does not include Qdrant RAG context retrieval (available only in production via InspireCodex.com)

2. **No Conversation Persistence**: Local development does not persist conversations to database (handled by InspireContinuum.com in production)

3. **API Key Required**: Requires valid OpenAI API key in `.env` file
