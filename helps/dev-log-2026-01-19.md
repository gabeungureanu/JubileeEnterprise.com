## 1. JubileeOutlook WPF - Rich Text Description Support

### Overview
This update adds the ability to create and edit richly formatted event descriptions using a RichTextBox editor. The formatting is stored as XAML FlowDocument format in the database.

### Completed Features

#### RichTextBox Editor Enhancement
- **Rich Text Formatting**: Full support for Bold, Italic, Underline, Strikethrough
- **Lists**: Bulleted lists, Numbered lists, and Checklists
- **Inserts**: Hyperlinks, Tables, Horizontal lines
- **Clear Formatting**: Option to remove all formatting from selected text

**Technical Implementation:**
The description is serialized as XAML using `XamlWriter.Save()` and deserialized using `XamlReader.Load()`:

```csharp
/// <summary>
/// Serializes the RichTextBox content as XAML for storage
/// </summary>
private string GetRichTextAsXaml()
{
    if (DescriptionRichTextBox == null) return string.Empty;

    var document = DescriptionRichTextBox.Document;
    var textRange = new TextRange(document.ContentStart, document.ContentEnd);

    if (string.IsNullOrWhiteSpace(textRange.Text))
        return string.Empty;

    using var stream = new MemoryStream();
    XamlWriter.Save(document, stream);
    stream.Position = 0;
    using var reader = new StreamReader(stream);
    return reader.ReadToEnd();
}
```

#### Backwards Compatibility
- Existing plain text descriptions continue to work
- Format detection by checking for `<FlowDocument` or `<Section` prefix
- Automatic fallback to plain text if XAML parsing fails

```csharp
private void LoadRichTextContent(string content)
{
    if (content.TrimStart().StartsWith("<FlowDocument") ||
        content.TrimStart().StartsWith("<Section"))
    {
        // Parse as XAML FlowDocument
        using var stream = new MemoryStream(System.Text.Encoding.UTF8.GetBytes(content));
        var flowDocument = XamlReader.Load(stream) as FlowDocument;
        if (flowDocument != null)
        {
            DescriptionRichTextBox.Document = flowDocument;
            return;
        }
    }
    // Fallback: treat as plain text
    SetRichTextBoxText(content);
}
```

## 2. Database Migration - Rich Text & Images Support

### New Migration Script
Created `0004_outlook_richtext_images.sql` to support rich text descriptions and event images.

### Schema Changes

#### outlook_calendar_events Table Updates
```sql
-- Format indicator for description field
ALTER TABLE outlook_calendar_events
ADD COLUMN IF NOT EXISTS description_format VARCHAR(20) DEFAULT 'plain';
-- Values: 'plain', 'xaml', 'html'

-- In-person vs virtual event indicator
ALTER TABLE outlook_calendar_events
ADD COLUMN IF NOT EXISTS is_in_person BOOLEAN DEFAULT TRUE;
```

#### New outlook_event_images Table
```sql
CREATE TABLE IF NOT EXISTS outlook_event_images (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    event_id UUID NOT NULL REFERENCES outlook_calendar_events(id) ON DELETE CASCADE,
    file_name VARCHAR(500) NOT NULL,
    file_path VARCHAR(1000),
    file_size BIGINT NOT NULL DEFAULT 0,
    mime_type VARCHAR(100) DEFAULT 'image/jpeg',
    width INTEGER,
    height INTEGER,
    storage_key VARCHAR(500),
    storage_provider VARCHAR(50) DEFAULT 'local',
    url VARCHAR(1000),
    thumbnail_url VARCHAR(1000),
    checksum VARCHAR(64),
    display_order INTEGER DEFAULT 0,
    added_by_user_id UUID,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
```
