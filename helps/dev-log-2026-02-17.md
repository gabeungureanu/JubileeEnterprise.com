## 6. Drag & Drop Events (Phase 3)

### What
Events can be dragged to move them to different time slots within time grid views.

### Implementation
- Native HTML5 drag API (consistent with mail MessageList pattern)
- `handleDragStart` stores event ID and original start time in `dataTransfer`
- Time columns are drop targets with `handleDragOver` and `handleDrop`
- Drop calculates new start time from Y position using `HOUR_HEIGHT` constant
- Snaps to 15-minute intervals
- Preserves event duration on move
- Visual highlight on drag-over (`calendar-grid__time-column--drag-over`)

### Files Modified
- `src/components/calendar/CalendarGrid/CalendarGrid.tsx` — Drag handlers, drop targets
- `src/components/calendar/CalendarGrid/CalendarGrid.css` — Drag-over highlight
- `src/pages/Calendar/CalendarPage.tsx` — `handleEventDrop` with API update

## 11. Print/Export iCal (Phase 6)

### What
Export calendar events as RFC 5545 compliant iCal (.ics) files or print the current view.

### Implementation
- `generateICalContent()` produces VCALENDAR with VEVENT entries
- Supports: DTSTART/DTEND (all-day and timed), SUMMARY, DESCRIPTION, LOCATION, ATTENDEE, CATEGORIES, STATUS, TRANSP, CLASS, VALARM (reminders), RRULE (recurrence)
- Line folding at 75 octets per RFC 5545
- Text escaping for special characters
- Skips expanded recurring occurrences (`_occ_` IDs)
- `downloadICalFile()` creates Blob and triggers download
- ExportDialog with format selector (iCal / Print), event count display

### Files Created

## Technical Notes

- **No new npm packages**: All features built with React 19, native HTML5 APIs, and existing dependencies
- **Native HTML5 Drag**: Consistent with mail MessageList drag pattern, no external DnD library
- **localStorage Pattern**: All client-side persistence uses `jubilee_{feature}_{item}` key format with try/catch error handling
- **Filter Pipeline**: CalendarPage applies filters via `useMemo` chain: raw events → calendar visibility → search query/category
- **File Upload**: Uses Hono's native `formData()` API on the backend; files stored with UUID names to prevent collisions
