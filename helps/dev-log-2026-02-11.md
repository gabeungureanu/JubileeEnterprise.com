## 1. Backend: Codex API - Contacts CRUD Endpoints

### Feature Overview
Added comprehensive contacts REST API to the Codex API service (`services/codex-api/src/index.ts`), providing full CRUD operations for contacts and contact groups.

### API Endpoints Added

**Contacts:**
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/contacts` | List all contacts for authenticated user |
| GET | `/api/contacts/:id` | Get single contact by ID |
| POST | `/api/contacts` | Create new contact |
| PUT | `/api/contacts/:id` | Update existing contact |
| DELETE | `/api/contacts/:id` | Soft-delete contact |
| POST | `/api/contacts/:id/restore` | Restore soft-deleted contact |
| DELETE | `/api/contacts/deleted/permanent` | Permanently delete all soft-deleted contacts |
| POST | `/api/contacts/batch/delete` | Batch soft-delete multiple contacts |
| POST | `/api/contacts/batch/favorites` | Batch add/remove favorites |
| POST | `/api/contacts/batch/category` | Batch set category |
| POST | `/api/contacts/import` | Import contacts from CSV/vCard |
| GET | `/api/contacts/export` | Export contacts to CSV/vCard |

**Contact Groups:**
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/contact-groups` | List all contact groups |
| POST | `/api/contact-groups` | Create contact group |
| PUT | `/api/contact-groups/:id` | Update/rename contact group |
| DELETE | `/api/contact-groups/:id` | Delete contact group |
| POST | `/api/contact-groups/:id/contacts` | Add contacts to group |
| DELETE | `/api/contact-groups/:id/contacts/:contactId` | Remove contact from group |
| GET | `/api/contact-groups/:id/contacts` | Get contacts in a group |

### Security Features
- JWT authentication on all endpoints via `requireAuth` middleware
- User ownership verification on all operations (contacts scoped to `userId`)
- Rate limiting on import/export endpoints
- Input validation and sanitization
- Audit logging for create, update, delete operations

## Technical Notes

- **MVVM Pattern**: CommunityToolkit.Mvvm `[RelayCommand]` auto-generates command properties by stripping "Async" suffix (e.g., `EditContactAsync()` generates `EditContactCommand`, not `EditContactAsyncCommand`)
- **API Integration**: All database operations go through `InspireCodex.com` API (Codex API on port 4001) per project governance rules - no direct database connections
- **Soft Delete**: Contacts use soft-delete pattern with `is_deleted` flag and `deleted_at` timestamp; permanent deletion only via "Empty Deleted Folder"
- **Contact Groups**: Many-to-many relationship through junction table; groups appear as sub-folders under "Your contact lists" in sidebar
- **Duplicate Detection**: On import, checks for matching display name + email; prompts user to skip or add anyway via `SkipDuplicateCheck` flag
