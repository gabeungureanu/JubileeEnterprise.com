### 8. ContactDetail — Responsive Action Buttons Fix

Fixed action buttons (Favorite, Email, Edit, Group, Delete) being cut off on smaller screens.

**Root Cause:** `.contact-detail__actions` had `display: flex` without `flex-wrap: wrap`. With 5 buttons at ~467px total width in a ~332px container, buttons overflowed and were clipped.

**Fix (CSS only):**
- Added `flex-wrap: wrap` to `.contact-detail__actions`
- Reduced button padding from `6px 12px` to `6px 8px`
- Added `flex-shrink: 0` on `.contact-detail__quick-btn` to prevent squishing

## Database Migration

### 16. Migration 0011 — Fix contact_groups user_id FK Constraint

**Problem:** `contact_groups.user_id` had `REFERENCES users(id) ON DELETE CASCADE` (UUID type with FK). Web frontend generates a synthetic UUID from email hash that doesn't exist in the `users` table, causing 500 errors on group creation.

**Fix:**
- Dropped FK constraint `contact_groups_user_id_fkey`
- Changed column type from UUID to VARCHAR(255) to match `user_contacts.user_id` behavior

**File:** `infrastructure/migrations/codex/0011_fix_contact_groups_user_id.sql`

## Technical Notes

- **Category derivation**: Categories are NOT stored in a separate table. The `user_contacts.category` VARCHAR(100) column is the source. Client-side `useMemo` extracts distinct values, matching WPF's approach.
- **Group membership reverse mapping**: Since there's no "get groups for contact" API endpoint, a reverse map is built client-side by fetching members for each group and inverting the relationship.
- **Contact-to-groups map refresh**: The `contactGroupMap` state is rebuilt on mount and after every mutation (add/remove member, group CRUD, contact CRUD) via `refreshData → buildContactGroupMap`.
- **InfoDialog pattern**: Centered modal popup for success/info messages with gold icon, title, message, and Close button. Used for group creation success, "coming soon" features, etc.
- **ConfirmDialog pattern**: Centered modal with Cancel and Confirm buttons. Used for delete confirmations, vCard share, empty trash, etc.
